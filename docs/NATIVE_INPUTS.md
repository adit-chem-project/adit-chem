# Reading and verifying native inputs

`adit.native_import.import_native(path, code=None)` reads an input and returns a `NativeImportResult` with a JSON-serializable `report()`. It never edits inputs or executes calculations, shell commands, or includes. The report records file SHA-256 hashes, source lines and values, unknown fields, and unsupported features.

Use `adit-convert import INPUT_DIR NEW_REVIEW_DIR` from the CLI. If the code cannot be identified, it still writes only `import_report.json` in the new review directory. No report can be saved when that directory itself cannot be created. Use `--code vasp|espresso|lammps|gromacs` to specify the code explicitly (`qe` is an alias of `espresso`).

| Input | Supported subset |
|---|---|
| VASP | INCAR + VASP 5 POSCAR + automatic Gamma/Monkhorst-Pack KPOINTS. Single point, unshifted automatic mesh, explicit element names. |
| QE | `pw.in`, scf, ibrav=0, CELL_PARAMETERS in Å, ATOMIC_POSITIONS in Å/crystal, gamma/automatic K_POINTS. Plain unique element labels. |
| LAMMPS | `in.lammps` + a data file referenced by relative path, explicit metal/real, atomic, p/f boundaries, lj/cut, pair_coeff. `run 0` or the limited NVE/NVT MD subset below. Element labels such as `# Si` in Masses are required; masses are never used to guess elements. |
| GROMACS | `grompp.mdp` + `conf.gro` / `.pdb` + `topol.top`. Reads the integrator, steps, temperature, pressure and cutoffs. The topology is recorded as a dependency, not interpreted. |

The VASP settings read are ENCUT / EDIFF / NELM / ISMEAR / SIGMA / ISPIN / ALGO / PREC / LREAL / NELMIN / LASPH / LMAXMIX / NBANDS / ISYM. For QE, the reader takes ecutwfc / ecutrho / occupations / smearing / degauss / nspin / input_dft / conv_thr / electron_maxstep / mixing_beta and the pseudopotential names in ATOMIC_SPECIES. VASP logicals written to LREAL / ALGO / PREC (e.g. `.FALSE.`) are kept as text. QE smearing also accepts the short spellings pw.x takes (`gauss`, `mp` / `m-p`, `cold` / `mv` / `m-v`, `fd` / `f-d`) and stores the long names. `tetrahedra_lin` / `tetrahedra_opt` / `from_input` have no shared field and are reported as unsupported. GROMACS mdp option names treat `_` and `-` alike, as GROMACS does.

Single-point inputs generated by ADIT within this subset can be imported. VASP SYSTEM is retained as a title in extra_incar. QE tstress / tprnfor are retained as output flags in extra.control. QE prefix / outdir / pseudo_dir are recorded in `not_applied` as the source layout. They are not applied to the regeneration destination or to parameter libraries, and the paths they refer to are never opened. Tests compare mapped fields, not whole-calculation equivalence.

Unknown or unsupported data make `spec` `None`, and successfully parsed values remain in the report. MD outside the LAMMPS subset below, relaxation, constraints, per-atom initial velocities, runtime variables, and inferred references to external potentials are unsupported. Limits are 8 MiB per file and 10,000 atoms. POTCAR is never opened.

A returned Spec is for review, not a claim of identical regeneration or executability. Every Spec value absent from the source is listed under `inferred_defaults`. In particular, the user should review parameter-library settings, POTCAR names, and runtime settings. Regeneration goes through the normal validation.

`complete=true` means only that the supported syntax was parsed. `ready_to_regenerate` is always false. Every QE UPF and the VASP POTCAR library appear in `unresolved_dependencies` with source line numbers. Matching file names do not verify existence, contents, licensing or copying.

A LAMMPS Spec is a review draft that refers to the original data file. Conversion of its settings to another code is blocked by the external-data safety check.

Additional LAMMPS MD support covers atomic / lj/cut / fully periodic NVE and constant-temperature Nosé–Hoover NVT whose entire command sequence matches the ADIT generator. metal time in ps is converted to fs, and real time in fs goes into the shared Spec as is. For initial velocities, the temperature, seed and initialization method of `velocity all create T seed mom yes rot no dist gaussian` are preserved, and per-atom velocities are not invented. Data-file velocities, restarts, temperature ramps, extra fix options, other thermostats, NPT and partial atom groups are rejected. The element of each atom type is read from the Masses comments or from the explicit `adit: atom types 1=Ar ...` at the top of a generated data file. VASP and QE MD are not supported.

MD references: [LAMMPS velocity](https://docs.lammps.org/velocity.html), [units](https://docs.lammps.org/units.html), [fix nve](https://docs.lammps.org/fix_nve.html), [fix nvt](https://docs.lammps.org/fix_nh.html).

Official references: [VASP INCAR](https://vasp.at/wiki/INCAR), [KPOINTS](https://vasp.at/wiki/KPOINTS), [POSCAR](https://vasp.at/wiki/POSCAR), [QE INPUT_PW](https://www.quantum-espresso.org/Doc/INPUT_PW.html), [LAMMPS read_data](https://docs.lammps.org/read_data.html), [LAMMPS run](https://docs.lammps.org/run.html).

## Verifying a generated bundle

`adit.native_verify.verify_generated_bundle(project_dir)` reads `spec.json` and the actual native inputs. Its result separates `preserved`, `mismatched`, and `unverifiable` fields and provides a JSON-serializable `report()`. It is read-only: it does not edit inputs or execute calculations.

Use `adit-convert verify GENERATED_DIR` from the CLI. The exit status is 0 when supported fields could be re-imported and no mismatch was found. Mismatches, unsupported inputs and missing inputs return 1. Add `--report NEW_FILE.json` to save details; it does not write to an existing file or inside the generated directory. Exit status 0 means **only that the mapped checks passed**, and `unverifiable` entries may remain. Do not read the result as equivalence of the calculation or as executability.

The scope is the same as the importer above. Only supported fields written explicitly in the source input are compared. A Spec default that merely matches does not count as "preserved". Pseudopotential contents, force-field correctness, runtime configuration, and whole-calculation equivalence are not established.

VASP atoms are compared in the same per-element order as the generator uses. LAMMPS coordinates are unverifiable if the source Spec refers to external data or requires cell rotation. Coordinates and cells use an absolute tolerance of 1e-8 Å. Other numeric comparisons use a relative tolerance of 1e-8 and an absolute tolerance of 1e-14. Integers, strings and booleans must match exactly. LAMMPS time is already converted to fs by the importer. K-points are compared as the actual mesh and shift.

For multi-stage calculations, the task of a preparatory input is not compared directly with the task of the overall Spec. If QE pseudopotential names were supplied by the generation settings and the source Spec does not specify them, they are marked unverifiable instead of mismatched.
