# examples/lammps_cu_nvt_generated —— LAMMPS generator output and the results of actually running it

NVT of Cu generated by the ADIT generator (`codes/lammps.py`), and the results of running it with LAMMPS (22 Jul 2025 update 5, conda-forge `lammps`).

| Item | Details |
|---|---|
| Structure | ASE `bulk("Cu", "fcc", a=3.615, cubic=True).repeat((3, 3, 3))` (108 atoms, periodic, cube 10.845 Å) |
| Interaction | `pair_style eam` / `pair_coeff * * Cu_u3.eam`. The potential is `examples/lammps_cu/Cu_u3.eam` (source in SOURCES.md in that directory) |
| Settings | units metal, NVT (Nosé-Hoover, `fix nvt`), 300 K, 1 fs × 300 steps, thermostat time constant 100 fs, trajectory every 50 steps |
| Command sources | The units, read_data, pair_style eam, velocity, fix nvt, dump custom, dump_modify element / sort, and write_data pages at https://docs.lammps.org/ |
| Run | `mpirun -np 1 lmp -in in.lammps -log log.lammps` (1 process, OpenMP 1 thread, nice 19, memory limit 1.5 GB). 2026-09-12 |
| Result | Normal termination. Run time 1.7 s (all of submit.sh). At step 300: temperature 252.67 K, potential energy -379.02162 eV (sum over 108 atoms), total energy -375.52698 eV |
| Trajectory | `traj.lammpstrj` (dump custom, columns id type element x y z, 7 frames). `final.data` is the last structure |

The temperature is a value in mid-fluctuation: 300 steps (0.3 ps) is only 3 times the thermostat time constant (0.1 ps).
This example checks that "the generated files run without errors". Do not use it for property values.
