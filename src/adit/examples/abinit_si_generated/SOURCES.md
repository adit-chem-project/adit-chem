# examples/abinit_si_generated —— SCF single point of diamond Si with ABINIT (run on 2026-09-13)

ABINIT input generated by ADIT, and the results of actually running it (text files only).

| Item | Value |
|---|---|
| Structure | Diamond-structure Si, primitive cell with lattice constant 5.43 Å (2 atoms). Built with `ase.build.bulk` |
| Settings | `ecut 8 Hartree`, `ngkpt 4 4 4` (no shift), `toldfe 1e-8`, `nstep 30`. The functional comes from the pseudopotential (`ixc` is not written) |
| Run | ABINIT 10.0.3 (conda-forge), 1 process, 1 thread |
| Result | `etotal = -8.8652901202 Hartree` (= -241.2368 eV, 2 Si atoms) |

**`ecut 8 Hartree` and `4×4×4` only show the format. They are not converged settings.**
For real calculations, check convergence with `adit-gen --scan method.ecut_ha=...` or similar.

## Pseudopotentials are not included

This calculation used the ABINIT test pseudopotential `14si.pspnc` (Troullier–Martins, in the ABINIT repository at
`tests/Pspdir/PseudosTM_pwteter/14si.pspnc`). **ADIT does not bundle pseudopotentials,
so it is not in this directory either.** To reproduce the calculation, get that file and
put it in the same directory as `input.abi` (`pp_dirpath "./"` in the input points there).

    https://raw.githubusercontent.com/abinit/abinit/master/tests/Pspdir/PseudosTM_pwteter/14si.pspnc

`method.pseudos` in `spec.json` still holds the file location given at generation (`/home/<user>/pseudos/14si.pspnc`).
If you put the file elsewhere, change that value and generate again.

## Files

| File | Contents |
|---|---|
| `input.abi` | ABINIT input written by ADIT (structure as `rprim` and `xred` in bohr) |
| `input.abo` | ABINIT main output. ADIT reads the last structure (`acell`, `rprim`, `xred`) from the table of variables at the end |
| `output.log` | Standard output. ADIT reads `Total energy (etotal) [Ha]` for each step from here |
| `code_version.txt` | ABINIT version recorded by `submit.sh` |

The large files ABINIT writes (`*_GSR.nc`, `*_WFK`, `*_DEN`, and others) are not included in this example (running it creates them).
