# examples/xtb_water_generated —— xtb input made by the generator, and the results of actually running it

Geometry optimization of a water molecule (GFN2-xTB) generated by the ADIT generator (`codes/xtb.py`), and the results of running it with xtb 6.7.1 (conda-forge).
xtb has no parameter files, so the generated files are complete as they are.

| Item | Details |
|---|---|
| Command-line argument source | https://xtb-docs.readthedocs.io/en/latest/commandline.html and `xtb --help` (6.7.1). `--gfn`, `--chrg`, `--uhf`, `--acc`, `--etemp`, `--opt [LEVEL]`, `--input`, `--parallel`, `--json` |
| xcontrol source | https://xtb-docs.readthedocs.io/en/latest/xcontrol.html : `$scc maxiterations`, `$opt maxcycle`, `$fix atoms:` (1-based), `$end` |
| xtb license | LGPL-3.0 (https://github.com/grimme-lab/xtb). The program comes from `xtb` on conda-forge |
| Result | Converged in 9 iterations. Total energy -5.070544 Eh (output.log). The optimized structure is in xtbopt.xyz |

For citations, follow the xtb documentation (GFN2-xTB: Bannwarth, Ehlert, Grimme, J. Chem. Theory Comput. 2019, 15, 1652).
