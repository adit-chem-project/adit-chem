# examples/cp2k_h2o_generated —— CP2K generator output (single point) and the results of actually running it

Single point of a water molecule generated by the ADIT generator (`codes/cp2k.py`), and the results of running it with CP2K 2026.2 (conda-forge `cp2k`, `cp2k.psmp`).

| Item | Details |
|---|---|
| Structure | ASE `molecule("H2O")`. Non-periodic. Cubic box with 6 Å edges (the "molecule box" on screen), centered with `&TOPOLOGY &CENTER_COORDINATES` |
| Settings | PBE, DZVP-MOLOPT-SR-GTH (O, H), GTH-PBE-q6 / GTH-PBE-q1, CUTOFF 280 Ry, REL_CUTOFF 40 Ry (both set to the CP2K default values as an example), POISSON_SOLVER MT, PERIODIC NONE |
| Basis sets and pseudopotentials | Only the 4 entries used, copied to `BASIS_adit` / `POTENTIAL_adit` from `BASIS_MOLOPT` and `GTH_POTENTIALS` in the CP2K data directory (part of the CP2K distribution, GPL-2.0-or-later) |
| Keyword source | The input reference written by `cp2k.psmp --xml` in CP2K 2026.2 (cp2k_input.xml; same content as https://manual.cp2k.org/) |
| Run | `mpirun -np 1 cp2k.psmp -i cp2k.inp` (OpenMP 1 thread). 2026-09-12 |
| Result | Normal termination. Run time 4.0 s. SCF converged in 10 iterations. Total energy -17.219399129357214 Hartree (`ENERGY| Total FORCE_EVAL`). Forces are on the `FORCES|` lines of output.log |

`tests/test_cp2k.py::test_cp2k_real_run` runs the same input and checks that the total energy agrees with this value to within 1e-5 Hartree.

## About the name (2026-09-14)

This calculation **was run before the rename (VISTA)**. For the rename (VISTA → ADIT),
file names and strings inside the files were changed to ADIT (to match what ADIT generates now).
**The calculation itself (numbers, convergence, software versions) is as it was run.**
