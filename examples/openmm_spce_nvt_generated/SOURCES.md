# examples/openmm_spce_nvt_generated —— NVT MD of 216 SPC/E water molecules with OpenMM (run on 2026-09-13)

OpenMM calculation directory generated by ADIT, and the results of actually running it. **ADIT does not create force fields, atom types or charges.**
The topology and coordinates are an unmodified copy of `examples/gromacs_spce/` (the SPC/E box bundled with GROMACS). The source and license are in
`SOURCES.md` in that directory.

| Item | Value |
|---|---|
| Calculation | NVT MD, 200 steps, time step 2 fs, 300 K, Langevin (time constant 100 fs → collision rate 1/100 fs⁻¹), recorded every 50 steps |
| Nonbonded | PME, cutoff 0.8 nm, `constraints = HBonds`, `rigidWater = True` (OpenMM default) |
| Run | openmm 8.4.0.dev-4768436 (conda-forge), Platform = CPU, `OPENMM_CPU_THREADS=1`. The random seed 12345 is passed to Langevin, so a rerun in the same environment gives the same values (checked: `results.json` also matches after generating again and rerunning). The input format was also checked with 8.6.1 (installing `openmm-plumed` downgraded openmm in this env from 8.6.1 to 8.4.0.dev) |
| Force field | GROMACS-bundled `oplsaa.ff/forcefield.itp` and `oplsaa.ff/spce.itp`, read from `include_dir` (not bundled here) |
| Result | Potential energy -9980 kJ/mol (-46.2 kJ/mol per water molecule), final temperature 295.3 K, 1293 degrees of freedom |

Degrees of freedom: 1293 = 648 atoms × 3 − 648 rigid-water constraints − 3 for removing center-of-mass motion. The potential energy per molecule is
the same order of magnitude as the SPC/E literature configurational energy of water (Berendsen, Grigera, Straatsma, J. Phys. Chem. 91, 6269 (1987)).
It comes from only 200 steps, so it is not treated as an equilibrium value.

## Files

| File | Contents |
|---|---|
| `run_openmm.py` / `openmm_settings.json` | Script and setting values written by ADIT (the same script for every calculation type) |
| `topol.top` / `conf.gro` | Copied topology and coordinates (`examples/gromacs_spce/`) |
| `md.log` | CSV from OpenMM `StateDataReporter` (step, time, energy, temperature, volume, density) |
| `results.json` / `final.pdb` | Final energy and temperature, and the last structure |
| `trajectory.dcd` | Trajectory from OpenMM `DCDReporter` (for VMD, OVITO, TRAVIS; ADIT does not read it) |
| `trajectory.extxyz` | Text trajectory written when `write_xyz_trajectory` is enabled (ADIT's RDF and MSD read this one) |
| `analysis/` | Output of `adit-analyze . --rdf --msd O` (with only 4 frames, the values only check the format) |
