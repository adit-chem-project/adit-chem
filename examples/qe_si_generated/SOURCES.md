# examples/qe_si_generated —— pw.x input made by the generator, and the results of actually running it

Structural relaxation of diamond Si (2 atoms, ASE reference state a = 5.43 Å) generated by the ADIT generator (`codes/espresso.py`), and the results of running it
with pw.x from Quantum ESPRESSO 7.5 (conda-forge). `pseudo/` (UPF) is not in the repository.

| Item | Details |
|---|---|
| Input variable source | https://www.quantum-espresso.org/Doc/INPUT_PW.html (calculation, nstep, forc_conv_thr, ecutwfc, ecutrho, occupations, smearing, degauss, nspin, tot_charge, tot_magnetization, conv_thr, electron_maxstep, cell_dofree, if_pos) |
| Writer | `ase.io.espresso.write_espresso_in` from ASE 3.29 |
| Official example | `PW/examples/example01` in QE (Si scf: ibrav 2, celldm 10.20, ecutwfc 18, conv_thr 1e-8; pseudopotential Si.pz-vbc). Here PBE from pslibrary is used, with ecutwfc / ecutrho at the values recommended in the UPF (44 / 175 Ry) |
| Pseudopotential | `Si.pbe-n-rrkjus_psl.1.0.0.UPF` from pslibrary 1.0.0 (from https://pseudopotentials.quantum-espresso.org/upf_files/ ; pslibrary is GNU GPL: https://dalcorso.github.io/pslibrary/) |
| Result | JOB DONE. Total energy -22.83956699 Ry. bfgs converged in 1 SCF and 0 steps (the starting structure is symmetric, so the forces are 0) |
