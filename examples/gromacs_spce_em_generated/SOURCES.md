# examples/gromacs_spce_em_generated —— GROMACS generator output (energy minimization) and the results of actually running it

Energy minimization of a box of 216 SPC/E water molecules generated by the ADIT generator (`codes/gromacs.py`), and the results of running it with GROMACS 2026.3 (conda-forge `gromacs`,
mixed precision, thread-MPI). The NVT that follows is in `examples/gromacs_spce_nvt_generated`.

| Item | Details |
|---|---|
| Input | `examples/gromacs_spce/topol.top` and `conf.gro` (spc216.gro bundled with GROMACS; source in SOURCES.md in that directory) |
| mdp | integrator steep, nsteps 50, emtol 1000 kJ mol⁻¹ nm⁻¹ (converted from the on-screen force tolerance 1.0364 eV/Å), coulombtype PME, rcoulomb = rvdw = 0.85 nm |
| mdp source | https://manual.gromacs.org/current/user-guide/mdp-options.html |
| Run | `gmx grompp -f grompp.mdp -c conf.gro -p topol.top -o adit.tpr` → `gmx mdrun -deffnm adit -ntmpi 1 -ntomp 1`. 2026-09-12 |
| Result | Normal termination. Run time 0.30 s. The largest force fell below 1000 kJ mol⁻¹ nm⁻¹ in 1 step (859.84 from the start, atom 103). Potential energy -9953.6836 kJ/mol |

With a cutoff of 0.9 nm, grompp stopped with "the cutoff is longer than half the shortest box edge". In minimization the neighbor-list radius is
1.05 times the cutoff (verlet-buffer-tolerance in the manual), and 0.9 × 1.05 = 0.945 nm exceeds 0.931 nm, half of the 1.862 nm box.
The generator's check uses this fact directly (`tests/test_gromacs.py::test_things_grompp_would_reject`).

## About the name (2026-09-14)

This calculation **was run before the rename (VISTA)**. For the rename (VISTA → ADIT),
file names and strings inside the files were changed to ADIT (to match what ADIT generates now).
**The calculation itself (numbers, convergence, software versions) is as it was run.**
