Strain runs for elastic constants, generated by ADIT 0.1.0a1 (dftbplus, clamped ions)

  components (Voigt 1=xx 2=yy 3=zz 4=yz 5=xz 6=xy): [1, 4], strains: [-0.005, 0.005] (4-6 engineering), 5 runs (with the unstrained e0)

== After running ==
  python elastic_collect.py   (collects the stress and writes the slopes C_ij [GPa] of straight-line fits including δ = 0 to elastic_constants.csv)
  ADIT does not judge the values (whether the strains are in the linear range); fit residuals go to elastic.json.

== Run on this PC ==
  bash submit.sh   (runs the strain runs in order; or run bash submit.sh inside each directory)

== Running on a cluster (ADIT does not submit) ==
  With each submit.sh generated for a cluster profile, submit them from this directory as below (they are independent).
  PBS:   for d in e0 e1_-0.005 e1_+0.005 e4_-0.005 e4_+0.005; do (cd $d && qsub submit.sh); done
  Slurm: for d in e0 e1_-0.005 e1_+0.005 e4_-0.005 e4_+0.005; do (cd $d && sbatch submit.sh); done
