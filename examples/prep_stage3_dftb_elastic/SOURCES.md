# Run of elastic constants (batch generation over strains + straight-line fit of the stress) — DFTB+ 25.1, mio-1-1 (2026-09-12)

## What this example is

Diamond cubic cell (8 C atoms, ASE `bulk("C", "diamond", a=3.567, cubic=True)`, lattice not relaxed): 4 runs with strains of ±0.005 on each of Voigt components 1 (xx) and
4 (yz, engineering strain), plus 1 unstrained run (e0), each as a DFTB+ single point (k-points 4×4×4, SCC).
Generated by calling, through the API, the same process as `adit-gen spec.json out/ --elastic=-0.005,0.005 --elastic-components 1,4` (`src/adit/elastic_setup.py`),
run, and then collected with `python elastic_collect.py`.

- These are single points, so the values are for fixed atoms (clamped-ion)
- For each component, a least-squares line is fitted to the stress σ_i(δ) over 3 points including zero strain, and the slope is C_ij (no symmetrization)
- The stress follows the ASE convention (negative in compression). The stress table in detailed.out of DFTB+ 25.1 was written with the sign where the mean of the diagonal equals
  Pressure in the same file (P = +tr/3), so the sign is flipped on reading (`src/adit/outputs.py`). Checked in this run:
  the e0 diagonal −1.389×10⁻⁴ au and Pressure −0.138911×10⁻³ au are the same value. Stretching xx by 0.5 % takes Pressure from −4.09 to −6.59 GPa; compressing it gives −1.50 GPa
- In the first collection, the 2 shear runs stopped: the relative difference of 2.5×10⁻⁶ between Pressure (6 significant digits) and the table (12 digits) exceeded the tolerance of the sign check (relative 10⁻⁶).
  The tolerance was changed to relative 10⁻⁴ and the data collected again
