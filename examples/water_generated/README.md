# examples/water_generated

The same calculation as `examples/water` (a hand-written input from the official tutorial),
run with **input generated by the ADIT generator (`codes/dftbplus.py`)**. These are the results. For validating phase 3.

- Generation settings: `spec.json` (mio-1-1, SCC, Rational optimization, MaxSteps 100, GradElem 1e-4)
- Files generated: `dftb_in.hsd`, `geometry.gen` (`skf/` is CC BY-SA 4.0 data, so it is not in the repository)
- Run results: `output.log`, `dftb_pin.hsd`, `detailed.out`, `geom.out.gen`, `results.tag`
- Result: ran to completion (Geometry converged, 10 steps). Total energy -4.0779379326 Hartree.
  Final coordinates are identical to `examples/water/geom.out.gen`


## Update of 2026-09-10 (Spec v2)

The force convergence criterion now uses eV/Å, so it is written with units as `Convergence { GradElem [eV/AA] = 0.00514221 }`
(1e-4 Hartree/Bohr converted; DFTB+ accepts unit modifiers, so DFTB+ does the conversion).
The results (total energy -4.0779379326 Hartree, final coordinates) did not change. `spec.json` is version 2.
