# Run of conformer candidates — RDKit 2026.03 (ETKDG + MMFF94) → xtb 6.7.1 GFN2 optimization (2026-09-12)

## What this example is

10 conformers of ethanol (SMILES `CCO`) were made with RDKit ETKDG and optimized with MMFF94. Going from lowest energy up, those within all-atom RMSD 0.3 Å
were dropped as duplicates, and the remaining 3 each became an xtb (GFN2-xTB) geometry optimization.
Generated by calling, through the API, the same process as `adit-gen spec.json out/ --conformers 10 --rmsd 0.3 --conf-all-atoms` (`src/adit/conformers.py`),
run with xtb in each directory, and tabulated with `adit-analyze out/ --scan`.

- The random seed is the default 12345. With seed 0, RDKit 2026.03 returned the same coordinates for all 10 (checked the same day; ADIT now stops on this)
- The threshold 0.3 Å was chosen for this example (ADIT has no default). The all-atom RMSD between anti and gauche was 0.41-0.43 Å, so
  at 0.5 Å they merged into 1. With the RMSD excluding hydrogens (the default), conformers that differ only in the OH orientation fall below 0.01 Å and count as duplicates
- The CREST input (crest/) is written because the code is xtb GFN2 (ADIT does not run it)

## Results (numbers only)

| Conformer | MMFF94 rank | Total energy after xtb optimization [eV] |
|---|---|---|
| conf_001 | 1 (lowest in MMFF) | -309.98849844 |
| conf_002 | 2 | -310.05575138 |
| conf_003 | 3 | -310.05575138 |

The energy order is reversed between MMFF94 and GFN2-xTB (conf_001 is lowest in MMFF, and after xtb optimization it is 67 meV above the other 2).
The xtb energies of conf_002 and conf_003 agree to 8 digits (presumably mirror images; not checked).
