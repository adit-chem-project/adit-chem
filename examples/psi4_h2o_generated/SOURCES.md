# examples/psi4_h2o_generated —— geometry optimization of a water molecule with Psi4 (run on 2026-09-13)

Psi4 input generated by ADIT, and the results of actually running it.

| Item | Value |
|---|---|
| Structure | Coordinates from ASE `molecule("H2O")` (non-periodic, charge 0, multiplicity 1) |
| Settings | Method `scf`, basis `cc-pVDZ`, `geom_maxiter 20`. No reference is written, so the Psi4 default (RHF) applies |
| Run | Psi4 1.11 (conda-forge), 1 thread (`psi4 -i input.dat -o output.log -n 1`) |
| Result | Converged in 4 steps, `energy_hartree = -76.0270327837`, optimized O-H = 0.946 Å, H-O-H = 104.6° |

**The method and basis only show the format. They are not ADIT recommendations.**
O-H 0.946 Å is a well-known value for RHF/cc-pVDZ water, and it is shorter than the measured value (0.958 Å).

## What ADIT does and does not do

- The input (`input.dat`) is psithon (the Psi4 input language). The atom order is ADIT's structure as is, and
  `no_reorient`, `no_com` and `symmetry c1` are added so that Psi4 does not rotate or translate the coordinates
- The last few lines of the input write `results.json` and `final.xyz`. The analysis reads those 2 files and
  the "Optimization Summary" table in `output.log` (the energy of each step)
- The method, basis, reference and convergence settings are **decided by the user**. ADIT does not choose them

## Files

| File | Contents |
|---|---|
| `input.dat` | Psi4 input |
| `output.log` | Psi4 output (given with `-o`). Contains the table of energies per step and the 2 `adit-psi4:` lines |
| `stdout.log` | What goes to the screen (optking progress). The reason is also shown here when Psi4 stops |
| `results.json` / `final.xyz` | Results written by the end of the input, and the optimized structure |
