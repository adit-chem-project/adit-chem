Single points on interpolated path images, generated by ADIT 0.1.0a1 (dftbplus)

== Reaction path (NEB) ==
  7 images including the end points (5 intermediate); all images in images.extxyz, settings in neb.json
  - interpolation: ASE NEB.interpolate (method = idpp, mic = False)
  - No climbing image is used. The highest-energy image need not coincide with the saddle point, so the rise to the highest image is not a barrier from a located transition state
  This is not an NEB optimization (only energies at the interpolated positions).
  The path length [Å] is path_length_ang in neb.json.

== After running ==
  adit-analyze <this directory> --scan   (energy per image)

== Run on this PC ==
  bash submit.sh   (runs the image runs in order; or run bash submit.sh inside each directory)

== Running on a cluster (ADIT does not submit) ==
  With each submit.sh generated for a cluster profile, submit them from this directory as below (they are independent).
  PBS:   for d in image_00 image_01 image_02 image_03 image_04 image_05 image_06; do (cd $d && qsub submit.sh); done
  Slurm: for d in image_00 image_01 image_02 image_03 image_04 image_05 image_06; do (cd $d && sbatch submit.sh); done
