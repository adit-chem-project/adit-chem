# Run of single points on reaction path images — DFTB+ 25.1, mio-1-1 (2026-09-12)

## What this example is

Ethane rather than ethanol (ASE `molecule("C2H6")`, ASE 3.29.0) is the initial state, and the structure with one CH3 rotated 60° about the C–C axis
is the final state. ASE `NEB.interpolate(method="idpp")` made 5 intermediate images, and each of the 7 images got a DFTB+ single point.
Generated by calling, through the API, the same process as `adit-gen spec.json out/ --neb start.xyz end.xyz --images 5 --neb-mode images` (`src/adit/neb_setup.py`),
and tabulated with `adit-analyze out/ --scan`.

- This is not an NEB optimization (only energies at the interpolated positions). The codes' own NEB (VASP, QE neb.x, CP2K BAND) is
  written with `--neb-mode native` (not run that day: no VASP on hand, and QE and CP2K NEB do not fit in a short run)
- idpp interpolates interatomic distances, so the intermediate images are not rigid rotations
- The initial state uses the ASE molecule coordinates as is, not optimized with DFTB+ (largest force in the initial state 0.82 eV/Å)
