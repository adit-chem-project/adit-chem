# examples/dftb_tio2_generated

The same calculation as `examples/dftb_tio2` (a hand-written input from the official recipe), run with **input generated by the ADIT generator (Spec v2, with periodic support)**.
These are the results. For validating V1-2.

- Generation settings: `spec.json` (mio-ext, SCC, single point, k-points 4×4×4 with shift 0.5)
- Result: ran to completion. Total energy -15.6210745499 Hartree. Matches `examples/dftb_tio2/output.log`
- Differences from the hand-written version: ProjectStates in Analysis (projected density of states) is not generated. Options { WriteResultsTag = Yes } and
  PrintForces are written. ParserVersion 14. SK files are copied to skf/ (not committed to the repository)
