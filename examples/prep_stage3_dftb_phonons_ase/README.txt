Phonon (finite displacement) runs generated by ADIT 0.1.0a1 (dftbplus, ase)

  supercell 2x2x2 (16 atoms), 12 displacements of 0.01 Å
  k-points are given as a mesh (4x4x4), so the same mesh is used for the supercell (the spacing becomes finer by the supercell factor).
  phonopy was not available, so the ASE Phonons displacements (each atom of the reference cell by ±x ±y ±z) were made; collection also uses ASE.
  DOS: q-point mesh 10x10x10, width 0.5 THz (ASE DOS)

== After running ==
  python phonon_collect.py   (with the Python that has ADIT installed; writes band.yaml; phonopy is needed if it was used here)
  then adit-analyze <this directory> plots the dispersion (it reads band.yaml and total_dos.dat)
  Frequencies in THz; negative values are imaginary (phonopy convention); ADIT does not judge stability.

== Run on this PC ==
  bash submit.sh   (runs the displacement runs in order; or run bash submit.sh inside each directory)

== Running on a cluster (ADIT does not submit) ==
  With each submit.sh generated for a cluster profile, submit them from this directory as below (they are independent).
  PBS:   for d in disp-001 disp-002 disp-003 disp-004 disp-005 disp-006 disp-007 disp-008 disp-009 disp-010 disp-011 disp-012; do (cd $d && qsub submit.sh); done
  Slurm: for d in disp-001 disp-002 disp-003 disp-004 disp-005 disp-006 disp-007 disp-008 disp-009 disp-010 disp-011 disp-012; do (cd $d && sbatch submit.sh); done
