# Run of phonons (finite displacement, no phonopy = ASE Phonons) — DFTB+ 25.1, mio-1-1 (2026-09-12)

## What this example is

A 2×2×2 supercell (16 atoms) was built from the diamond primitive cell (2 C atoms, ASE `bulk("C", "diamond", a=3.567)`, lattice not relaxed),
and the 12 displacements used by ASE Phonons (each atom of the reference cell by ±x ±y ±z, 0.01 Å; the ASE default) each became a DFTB+ single point
(k-points 4×4×4, SCC). Generated by calling, through the API, the same process as `adit-gen spec.json out/ --phonons 2x2x2 --phonon-backend ase --phonon-dos-mesh 10x10x10 --phonon-dos-width 0.5`
(`src/adit/phonon_setup.py`), run, and then collected with `python phonon_collect.py`.

- Collection builds force constants with ASE Phonons (read defaults: Frederiksen acoustic sum rule), computes frequencies along the standard ASE path,
  and writes them with the same keys as phonopy's band.yaml (a note at the top says "not written by phonopy")
- DOS uses q-points 10×10×10 and Gaussian width 0.5 THz (chosen for this example; ADIT has no default)
- Checked that the analysis reader (analyze_phonopy in `src/adit/analysis/phonons.py`) can read band.yaml and total_dos.dat

## Results (numbers only; no judgment on stability)

Path GXWKGLUWLK,UX, frequencies −4.275 to 44.68 THz, 24 negative values (imaginary frequencies).
